# システム通知

システム通知は、スケジュールの実行結果、ユーザーの回答が必要な事項、システムのお知らせなど、プラットフォームと各製品から送られるメッセージをまとめて受け取るための機能です。通知は通知センターに保存され、一部の通知はポップアップでも表示されるため、現在のページを離れずに内容を確認したり、その場で回答を選んだりできます。

## 通知センターを開く

<figure><img src="../.gitbook/assets/image (80).png" alt=""><figcaption></figcaption></figure>

1. ページ右側の通知アイコンをクリックします。
2. 通知パネルが開き、最近受け取った通知を確認できます。
3. 任意の通知をクリックすると、詳細が開きます。
4. すべての通知履歴を表示するには、パネル下部の **すべて表示** をクリックします。

## 通知の分類

通知センターは次の 2 つの分類に分かれています。

### 個人通知

<figure><img src="../.gitbook/assets/image (577).png" alt=""><figcaption></figcaption></figure>

現在のユーザーに直接送られた通知が表示されます。例：

* スケジュールのトリガーまたは実行完了の通知
* Agent の実行中に送られるメッセージ
* ユーザーの回答や選択が必要な事項
* 各製品から送られる個人向けのリマインダー

### お知らせ

<figure><img src="../.gitbook/assets/image (578).png" alt=""><figcaption></figcaption></figure>

サービスのお知らせ、システムメンテナンス、バージョン更新など、システムから発表されるお知らせが表示されます。

## 通知の内容

各通知には次の情報が含まれる場合があります。

<table data-search="false"><thead><tr><th>項目</th><th>説明</th></tr></thead><tbody><tr><td>送信元の製品</td><td>通知を送った製品またはサービスを表示します。例：AI Studio、Portal、MCPHub。</td></tr><tr><td>通知日時</td><td>通知が作成または送信された日時を表示します。</td></tr><tr><td>タイトル</td><td>通知の主なイベントや対応が必要な事項を示します。</td></tr><tr><td>メッセージの発信元</td><td>メッセージを生成した Agent、スケジュール、または機能を表示します。</td></tr><tr><td>ステータス</td><td>通知に対応が必要かどうかを表示します。例：「対応待ち」「期限切れ」。</td></tr><tr><td>詳細</td><td>実行結果、メッセージの内容、または選択できる回答を表示します。内容は書式付き表示（HTML）に対応しており、見出し、リスト、表、リンクなどを表示できます。</td></tr></tbody></table>

## ポップアップ通知

<figure><img src="../.gitbook/assets/image (579).png" alt=""><figcaption></figcaption></figure>

**ポップアップ通知** をオンにすると、システムの操作中に通知がポップアップで表示されます。

ポップアップ通知には次の内容が含まれる場合があります。

* 通知のタイトル
* 発生日時
* 発信元または送信者
* 実行結果またはメッセージの内容
* その場で操作できる回答の選択肢

ポップアップ通知をオフにしても、ポップアップが表示されなくなるだけで、通知は削除されません。受け取ったメッセージは通知センターで確認できます。

ポップアップを一時的に閉じた場合も、後から通知センターで通知の内容を開き直せます。

## スケジュールの通知

スケジュールが設定時刻になってトリガーされると、システムが通知を作成します。通知にはスケジュール名、実行日時、実行結果が表示されます。

スケジュールの通知を確認するには：

1. 通知アイコンをクリックして通知センターを開きます。
2. 該当するスケジュールの通知を探します。
3. 通知をクリックして、スケジュールの実行結果と詳細を確認します。
4. 確認が終わったら、右上の「×」をクリックしてウィンドウを閉じます。

ポップアップ通知がオンの場合、スケジュールの通知が現在のページに直接表示されることもあります。

## 回答が必要な通知

スケジュール、Agent、またはそのほかの機能がユーザーの判断を必要とする場合、回答が必要な通知が送信されます。たとえば、ワークフローが[人による入力](../agent-zhi-nan/gong-zuo-liu-cheng-jie-dian.md)ノードに到達すると、確認者にこの通知が届きます。

人による入力ノードの場合、通知には次の内容が含まれます：

<table data-search="false"><thead><tr><th width="160">項目</th><th>説明</th></tr></thead><tbody><tr><td>タイトル</td><td>Agent のアイコンと名前、および「回答が必要です」が表示されます。</td></tr><tr><td>メッセージ</td><td>ノードで設定したメッセージが表示されます。</td></tr><tr><td>操作ボタン</td><td>会話内のカードと同じ配置で表示されます。選択肢が多い場合はスクロールして確認できます。</td></tr><tr><td>会話に戻る</td><td>右上に表示されます。クリックすると元の会話に戻ります。左側の機能メニューは表示されたままです。</td></tr></tbody></table>

操作方法：

1. 回答が必要な通知を開きます。
2. 通知のメッセージを確認します。
3. 操作の 1 つをクリックして回答を送信します。
4. システムが選択を受け取ると、回答に従って後続の処理を続行します。

「会話に戻る」をクリックすると、Agent の権限を持つユーザーは元の会話に移動します。権限のないユーザーには「権限がありません」と表示されますが、通知内で操作をクリックして回答することはできます。

回答が必要な通知はスケジュールから届くとは限らず、Agent の実行中や、通常の会話で回答が必要になった場合にも表示されます。

現在、通知内では用意された選択肢を選ぶことのみ可能で、テキストの直接入力やフォームの記入には対応していません。

## 通常の通知と対応待ちの通知の違い

| 通知の種類   | 使い方                                                                                             |
| ------- | ----------------------------------------------------------------------------------------------- |
| 通常の通知   | 実行結果やメッセージを伝えるための通知です。開くと詳細を確認でき、それ以上の操作は不要です。                                                 |
| 対応待ちの通知 | <p>「対応待ち」と表示され、ユーザーが回答を選ぶか指定の操作を完了しないと、処理は続行されません。<br>「期限切れ」は、指定の操作の期限が過ぎたことを示します。</p> |

## 注意事項

* 通知の内容と利用できる操作は、送信元の製品や機能によって異なります。
* ポップアップ通知をオフにしても、受け取った通知は通知センターで確認できます。
* 通知に「対応待ち」と表示されている場合は、詳細を開いて回答が必要かどうかを確認してください。
* 現在、通知内では用意された選択肢のみ操作でき、フォームの直接記入には対応していません。
* 通知をクリックする前に、送信元の製品、送信日時、メッセージの発信元を確認し、誤った通知に対応しないようにしてください。
