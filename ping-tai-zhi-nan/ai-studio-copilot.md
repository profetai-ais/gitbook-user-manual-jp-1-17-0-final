# AI Studio Copilot

<figure><img src="../.gitbook/assets/image (586).png" alt=""><figcaption></figcaption></figure>

AI Studio Copilot はシステムに組み込まれた製品アシスタントです。機能や操作方法の確認、Agent ソリューションの計画、利用時の問題のトラブルシューティング、要件が AI Studio と AutoML のどちらに適しているかの評価を支援します。

Copilot は質問の種類に応じて、関連する製品ドキュメント、機能情報、既知の問題を参照し、実行できる説明にまとめます。既存の情報だけでは判断できない場合は、必要な情報を追加で質問するか、管理者やコンサルタントへの確認が必要であることを明示します。

> Copilot は操作ガイド、診断、提案を提供しますが、ユーザーに代わってシステム設定を変更したり、変更を実行したりすることはありません。

## Copilot を開く

<figure><img src="../.gitbook/assets/image (587).png" alt=""><figcaption></figcaption></figure>

1. 画面右下の青い **Copilot** アイコンをクリックします。
2. 入力欄に自然な文章で質問を入力します。
3. 特定のページ、Agent、エラーに関する質問の場合は、利用中の機能、操作の目的、エラーメッセージの全文もあわせて入力すると、より正確な回答が得られます。

## 質問できる内容

Copilot は質問内容に応じて適切な処理方法を選びます。一度に 1 つの主な質問に絞ると、回答をそのまま活用しやすくなります。

### 機能と操作の確認

機能の用途、操作場所、設定手順、権限や前提条件のほか、機能同士の違いの比較にも向いています。

例：

* Skill を Agent に組み込むにはどうすればよいですか？
* ナレッジベースと DB MCPツールの違いは何ですか？
* Agent のメモリーはどこで設定しますか？
* Canvas とは何ですか？どうやって開きますか？
* ある機能を使うにはどのような権限が必要ですか？

Copilot は製品マニュアルをもとに操作手順をまとめます。ドキュメントに対応する画面がある場合は、実際の画面と照らし合わせられるよう、スクリーンショットと出典も提示することがあります。

### ソリューションの提案

達成したい目標を伝えると、Copilot はどの機能を使うのが適切かを判断し、推奨する組み合わせ、設定の順序、必要な条件、制限事項をまとめます。

例：

* 社内 SOP を読んで質問に答える Agent を作りたいのですが、どの機能を使えばよいですか？
* Agent に質問の種類を自動判定させ、それぞれ専門の Agent に処理させたい場合、どのように設計すればよいですか？
* データベースの正確なレコードを検索したい場合、ナレッジベースと MCPツールのどちらを使うべきですか？

情報が足りない場合、Copilot はまずデータの種類、利用環境、現在の設定、外部連携の要件などを質問することがあります。製品として十分な根拠がない場合もそれを明示し、確認されていない機能の組み合わせを勝手に提案することはありません。

### 問題の診断

エラーメッセージ、機能が使えない、ボタンが表示されない、実行に失敗する、結果がおかしいといった状況に向いています。

例：

* ある機能やボタンが表示されないのはなぜですか？
* Workflow の実行に失敗しました。どこを確認すればよいですか？
* API Tool で `401 Unauthorized` が表示される場合はどうすればよいですか？
* Agent がナレッジベースの内容を見つけられないのは、どこに問題がありそうですか？

Copilot はまず既知の問題と製品ドキュメントを照合し、考えられる原因と対処手順を提示します。該当する Known Issue が見つかった場合は、問題番号、期待される動作、現在の動作、利用できる暫定対処が回答に含まれることがあります。アカウントの状態、権限、リアルタイムの環境情報に関わる場合は、管理者や関係者に確認するよう案内します。

### 実現可能性と製品の選択

ある要件が実現できるか、AI Studio と AutoML のどちらを使うべきか、標準機能で対応できるか、外部システムとの連携が必要かといった質問に向いています。

例：

* この要件には AutoML と AI Studio のどちらを使うべきですか？
* AI Studio は社内の既存データベースや API と連携できますか？
* このプロセスは Agent だけで完結できますか？それとも MCPツールやほかの外部システムが必要ですか？
* ドキュメントの Q&A、データ検索、外部操作を 1 つのプロセスにまとめることはできますか？

回答には、要件に応じた実現可能性の判断、その理由、推奨する実装方法、事前に確認すべき前提、次のステップの提案が含まれます。中核となる機能が現在確認済みの製品範囲外の場合、Copilot はコンサルタントへのさらなる確認が必要であることを示します。

## より詳しい情報を伝えるには

背景情報が具体的であるほど、Copilot は正しいドキュメントや問題の範囲を見つけやすくなります。

| 質問の種類        | 伝えるとよい情報                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------- |
| **操作に関する質問** | 利用中のモジュールやページ、行いたい操作、どこまで進んでいるか。                                                                   |
| **エラーの診断**   | エラーコードとメッセージの全文、発生したページ、きっかけとなった操作、期待した結果と実際の結果。エラーの原文はそのまま残してください。                                        |
| **ソリューションの計画** | 達成したい目標、データの形式、既存の Agent／ナレッジベース／ツール、外部システムとの連携が必要かどうか。                                           |
| **実現可能性の評価**  | 要件の範囲、必要な機能、既存のデータ、外部システムと API の状況、期待する出力や判断基準。                                                    |

重要な条件が不足している場合、Copilot は通常、必要な質問をいくつか先に行います。情報を補足した後は、同じ会話の中で質問を続けられます。

## エラー発生時に Copilot に質問する <a href="#yu-dao-cuo-wu-shi-xun-wen-copilot" id="yu-dao-cuo-wu-shi-xun-wen-copilot"></a>

Agent の応答に失敗してエラーメッセージが表示された場合、エラーメッセージを自分でコピーしなくても、Copilot に原因の分析を直接依頼できます。

> 注意：
>
> * 質問ボタンをクリックするたびに、新しい Copilot の会話が開きます。Copilot がほかの質問に回答中の場合は、現在の回答を中断するかどうかを確認されます。
> * Copilot の提案は参考情報です。ログインのタイムアウト、権限不足、システム障害など、一部のエラーは管理者や技術サポートへの確認が必要です。

### 会話中にエラーが発生した場合

<figure><img src="../.gitbook/assets/image (584).png" alt=""><figcaption></figcaption></figure>

1. エラーメッセージにマウスカーソルを合わせます。
2. 質問ボタンをクリックすると、画面右側に Copilot が開き、元の質問とエラーメッセージが自動的に入力されます。
3. Copilot が考えられる原因を分析し、対処方法を提案します。
4. 提案を確認したら、会話画面に戻って提案どおりに調整し、もう一度試します。

> 注意：
>
> この機能は Agent 設定ページのデバッグプレビューでも利用できます。

## 注意事項

* Copilot の回答は、現在参照できる製品ドキュメント、機能情報、既知の問題に基づいています。記載されていない機能を、対応済みとしてそのまま扱うことはありません。
* データベース、外部 API、MCP との連携には、接続可能なサービス、適切な権限、認証情報、明確なデータ形式が事前に必要です。
* 個人アカウント、ワークスペースの権限、リアルタイムのシステム状態に関する質問は、管理者による確認が必要な場合があります。
* 価格、SLA、ロードマップ、特定バージョンの制限、法令遵守、正式な確約については、公式情報またはコンサルタントの確認結果に従ってください。
* 複雑またはリスクの高い要件は、まず範囲を絞って POC を行い、検証結果をもとに導入の拡大を判断することをおすすめします。
* AI Studio Copilot は Workforce の実行枠を使用します。Workforce の枠がすべて使用中の場合、リクエストはいったん待機列に入り、枠が空いてから処理が始まることがあります。
