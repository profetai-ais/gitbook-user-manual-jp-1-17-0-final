# スケジュール

## 概要

<figure><img src="../.gitbook/assets/image (700).png" alt=""><figcaption></figcaption></figure>

Agent 設定ページのスケジュールには、現在の Agent に関連するすべてのスケジュールが一覧表示されます。内容はスケジュール管理ページと同じですが、現在の Agent であらかじめ絞り込まれているため、Agent を編集しながらそのスケジュールを直接確認・管理でき、スケジュール管理ページに切り替えて検索する必要がありません。

## できること

* **スケジュールの確認**：この Agent のスケジュール一覧とステータスを確認します。
* **スケジュールの追加**：作成手順はスケジュール管理ページと同じですが、Agent は現在の Agent に固定されており、ほかの Agent を選ぶことはできません。詳しい手順はスケジュールの作成を参照してください。
* **ログの確認**：スケジュールの詳細ページで、実行ごとの記録と結果を確認します。ログの確認を参照してください。
