  Agent は会話形式のアプリケーションです。ユーザーがテキスト（プロンプト）を入力すると、用途に応じた処理を経て大規模言語モデル（Large
  Language Model, LLM）に渡され、回答が得られます。

# Agent の概要

## **主なメリット**

<figure><img src="../.gitbook/assets/image (658).png" alt=""><figcaption></figcaption></figure>

* **多様性**：さまざまなニーズに応える複数の種類の Agent を用意しており、簡単な設定で高品質な Agent アプリケーションを作成できます。
* **ガバナンス**：Agent の利用権限を管理でき、生成 AI の活用を社内規定に沿ったものにできます。
* **正確性**：ナレッジベースの情報をもとに回答を生成するため、ハルシネーション（hallucination）のリスクを抑えられます。
* **柔軟性**：ハイブリッドな利用シナリオに対応しており、開発者は必要に応じていつでも LLM のモデルやサービスを切り替えられます。
