## **主な機能と技術的な特長**

* **ナレッジベース**：3 つの簡単なステップでドキュメントのナレッジベースを構築できます。大規模言語モデルの内蔵知識の不足や、信頼性の低い回答といった課題を解決します。また、分野の専門家に権限を付与して各自のナレッジベースを安全に管理・維持させることで、重要な知識の流出を防げます。
* **Agent**：用途に応じた Agent をすばやく作成し、権限を付与してすぐにユーザーが利用できるようにします。
* **プロンプトの活用／テンプレート管理**：よく使うプロンプトを定型化してアプリとして提供します。ユーザーは重要な情報を入力するだけで精度の高い回答が得られ、長いプロンプトを自分で入力する必要がありません。
* **AI ワークフロー（AI Workflow）**：柔軟な AI ワークフローの仕組みにより、さまざまな RAG のシナリオに対応し、外部検索とも連携できます。RAG の設計効率が上がり、AI Studio の活用の幅が広がります。

> **注意：** 以下のスクリーンショットの情報は参考用です。実際の会話履歴、Agent、プロンプトテンプレートなどは、お使いの環境の内容をご確認ください。
