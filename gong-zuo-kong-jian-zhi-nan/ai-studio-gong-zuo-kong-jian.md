## リンクから Agent を開く

<figure><img src="../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

ほかのユーザーが共有された Agent のリンクを開くと、直接ワークスペースに移動します。

* システムはまずその Agent をユーザーのワークスペースに追加してから会話を開くため、探索で探す必要はありません。
* 左側の機能メニューは表示されたままなので、ほかの機能にも切り替えられます。
* ページを再読み込みしても、同じ Agent が重複して追加されることはありません。

通知、スケジュールの履歴、Agent の設定ページから会話のリンクを開いた場合も、同様にワークスペースに移動し、左側の機能メニューが表示されたままになります。自分で作成してまだ公開していない Agent でも、リンクから開くと過去の会話を読み込めます。

## **Agent を探してお気に入りに追加する**

<figure><img src="../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

1. ページ左側のメニューで **ワークスペース** をクリックします。
2. 使いたい Agent にマウスカーソルを合わせるか、検索欄にキーワードを入力して Agent を検索します。
3. Agent を選択し、カード上の「お気に入りに追加」ボタンをクリックします。
4. ページ上部の **お気に入り** ボタンをクリックして個人エリアに切り替え、追加した Agent があることを確認します。
