# パーソナライズ

## 概要

パーソナライズは、Agent が重要な情報を「覚えて」、その後のやり取りでも「使い続ける」ための機能です。会話の一貫性とタスク処理の効率を高めます。やり取りの中で好み、背景情報、よく使う設定、プロジェクトの文脈、決まった形式などを伝えると、システムはそれを再利用できるメモリーとして整理し、Agent がその後の会話で自動的に参照します。同じ説明を繰り返したり、何度も確認したりする手間が減ります。

たとえば、呼び方、口調、出力形式（箇条書き／表／段落）、よく扱う製品やプロジェクト名、進め方の好み、よく使う判断基準、長期的に一貫させたいルールなどを、メモリーとして保持し、適切なタイミングで適用できます。

メモリー機能は、右上のアバターにある **パーソナライズ** タブから利用できます。

### あなたについて

個人情報を追加すると、Agent がよりパーソナライズされた回答を生成できます。

<figure><img src="../.gitbook/assets/image (238).png" alt=""><figcaption></figcaption></figure>

### メモリー

メモリーは **メモリーの保存** と **メモリーの参照** に分かれています。

<figure><img src="../.gitbook/assets/image (239).png" alt=""><figcaption></figcaption></figure>

* **メモリーの保存**：オンにすると、Agent がメモリーを保存できます。
* **メモリーの参照**：オンにすると、Agent が回答時にメモリーストアのメモリーを引用できます。

## メモリーの管理

メモリーの管理は **管理** ボタンから行います。**個人メモリー** と **Agent メモリー** に分かれています。

<figure><img src="../.gitbook/assets/image (640).png" alt=""><figcaption></figcaption></figure>

### 個人メモリー

メモリーの参照がオンのとき、ここに保存されたメモリーはすべての Agent から利用できます。個人メモリーは最大 50 件まで保存できます。

> Note：保存上限を超えると、使用頻度が最も低いメモリーから自動的に削除されます。

<figure><img src="../.gitbook/assets/image (641).png" alt=""><figcaption></figcaption></figure>

### Agent メモリー

メモリーの参照がオンのとき、Agent は自分のメモリーストア内のメモリーを利用できます。Agent ごとに最大 50 件まで保存できます。

> Note：保存上限を超えると、使用頻度が最も低いメモリーから自動的に削除されます。

## メモリーの保存方法

1. メモリー機能を使う前に、**メモリーの保存** がオンになっていることを確認します。
2. 会話画面で会話する Agent を選択し、覚えてほしい内容を入力します。
3. 保存に成功すると、Agent から **パーソナライズ → メモリー管理** で確認できる旨が案内されます。
