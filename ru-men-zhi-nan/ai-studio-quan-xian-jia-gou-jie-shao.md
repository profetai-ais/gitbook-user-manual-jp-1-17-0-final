# AI Studio の権限構成

## 権限の構成

<figure><img src="../.gitbook/assets/image (508).png" alt=""><figcaption></figcaption></figure>

### 機能レベル（Root）

Agent 一覧、ナレッジベース一覧、テンプレート一覧など、「ある種類の機能」全体の利用・管理権限を管理します。この階層によって、その機能に入れるか、新しい項目を作成できるか、その機能のメンバー一覧を管理できるかなどが決まります。

Root の閲覧権限は AI Studio のロール設定によって決まります。AI Studio のロールについては [AI Studio のロールと権限](ai-studio-jue-se-yu-quan-xian-shuo-ming.md) を参照してください。

### 項目レベル（Object）

特定の Agent、特定のナレッジベース、特定のテンプレートなど、機能内の「個々の項目」の権限を管理します。この階層では項目ごとにメンバーのロールを設定し、誰が編集できるか、誰が利用のみできるか、誰がメンバーを管理できるかなどを決めます。

Object の閲覧権限は Root のロール設定によって決まります。Root のロールについては [モジュール別の権限ロール](quan-xian-gong-neng-jie-shao.md) の各 **一覧ロール権限** を参照してください。

> 注意：既定では、管理権限を持つロールのみが該当する機能に入り、管理操作を行えます。一部の機能が表示されない、または操作できない場合は、「機能レベル」と「項目レベル」の権限が付与されているか管理者に確認してください。

## 権限の判定方法

<figure><img src="../.gitbook/assets/image (509).png" alt=""><figcaption></figcaption></figure>

システムはまずユーザーのその機能における Root 権限を判定し、ユーザーの Root ロールに応じて Object 権限をさらに判定する必要があるかを決めます。

* ユーザーがその機能の **一覧管理者** である場合、その機能内のオブジェクトを管理できます。個々のオブジェクトの Object 権限がなくても、追加・編集・削除などの操作を行えます。
* ユーザーがその機能の **一覧ユーザー** である場合、アクセス・操作できるオブジェクトの範囲は Object 権限によって判定されます。
* ユーザーがその機能の Root 権限を持たない場合、その機能のページに入ることも、機能内のオブジェクトを操作することもできません。

### 注意事項

ユーザーが実際に閲覧・操作できる内容は、Root 権限と Object 権限の設定によって異なります。特定の機能やオブジェクトが表示されない場合は、そのユーザーが該当機能の Root 権限を持っているか、そのオブジェクトに対応する Object 権限が付与されているかを確認してください。

ユーザーに機能内のすべてのオブジェクトを管理させたい場合は、そのユーザーをその機能の Root Admin に設定します。特定のオブジェクトだけを操作させたい場合は、Object 権限で設定します。

権限を変更した後、最新の権限が反映されるまでに、ページの再読み込みや機能ページへの再入場が必要になる場合があります。

## Root 権限

<figure><img src="../.gitbook/assets/image (594).png" alt=""><figcaption></figcaption></figure>

Root 権限はモジュール全体の最も外側にある権限で、ユーザーがある機能の中で操作できる全体的な範囲を制御します。Root 権限は通常、次のロールに分かれます。

* **一覧管理者**
* **一覧ユーザー**

Root ロールごとに実行できる操作の範囲は、機能の設計によって異なります。

ある機能の Root 権限を持っている場合にのみ、その機能のページに入ったり、主な操作を利用したりできます。たとえば Agent、ナレッジベース、テンプレートなどの機能モジュールに入る場合です。

このうち **一覧管理者** はその機能における最上位の管理権限を持ちます。ある機能の一覧管理者であれば、特定の Object 権限を付与されていなくても、その機能内のオブジェクトを追加・編集・削除できます。

## **Object 権限**

<figure><img src="../.gitbook/assets/image (595).png" alt=""><figcaption></figcaption></figure>

Object 権限は、機能内でユーザーがアクセス・操作できる個々のオブジェクトを制御します。

1 つの機能には、異なる Agent、ナレッジベース、テンプレートなど複数のオブジェクトが含まれる場合があります。ユーザーがその機能の一覧管理者でない場合、システムは各オブジェクトの Object 権限に基づいて、そのオブジェクトを閲覧・利用・編集・管理できるかを判定します。

## AI Studio と Root 権限の同期

ログイン後、システムはそのアカウントの現在の AI Studio 権限に合わせて一覧権限を自動的に補完します。

たとえば **AI Studio ドメインユーザー** のアカウントでは、ログイン後に Agent、ナレッジベース、能力（スキル、MCP）、テンプレート（ワークフロー、プロンプト）、分析（レポート）の **一覧ユーザー** 権限が自動的に付与されます。

この同期は **ログイン時にのみ実行され、不足している権限だけを補完します**。**既存の一覧権限には影響しません**。また、AI Studio 側のアカウント権限が後から変更されても、自動同期は実行されません。
