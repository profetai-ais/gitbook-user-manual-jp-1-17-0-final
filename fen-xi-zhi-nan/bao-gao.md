# レポート

## 概要

レポートでは AI Studio の使用状況と運用分析のレポートを提供し、管理者がプラットフォームの Token、Quota、タスクの実行、機能の使用状況を追跡できるようにします。視覚的なダッシュボードで Session、Memory、Workflow、RAG、Speech などに関するデータを確認でき、コスト分析、使用量の追跡、運用管理の参考にできます。

このページではレポートとデータの可視化ツールがまとめられており、権限に応じて作成済みの Dashboard、Chart、Dataset を確認できます。

## Dashboard

**Dashboard** は、作成済みの分析ダッシュボードをまとめて表示します。各 Dashboard には 1 つ以上のグラフが含まれ、特定のテーマのデータの状況を確認できます。

よくある Dashboard の分析テーマには次のようなものがあります。

* Agent の使用状況
* Token の使用量とコスト
* ユーザーのアクティビティ分析
* ナレッジベースと Agent の関連
* 権限とアクセスの状況
* タスクの実行と異常の監視

Dashboard の一覧では、名前、ステータス、所有者、最終更新日時を確認できます。Dashboard 名をクリックすると、その Dashboard の詳しいグラフを確認できます。

## Chart

**Chart** では、レポートのグラフを管理または作成します。グラフを作成するには、まずデータセットを選び、次にグラフの種類を選びます。

次のようなさまざまなグラフの種類に対応しています。

* Area Chart
* Bar Chart
* Big Number
* Line Chart
* Pie Chart
* Table
* Heatmap
* Pivot Table
* Scatter Plot
* Treemap

グラフの種類によって、表示に適したデータが異なります。たとえば、推移のデータには Line Chart、割合のデータには Pie Chart、明細のデータには Table、重要な数値には Big Number が適しています。

Chart の作成機能は通常、レポートの管理権限を持つユーザーに提供されます。一般ユーザーは、権限に応じて既存のグラフと Dashboard を確認できます。

## Dataset

**Dataset** には、グラフや Dashboard の作成に使えるデータセットが表示されます。Dataset はレポート分析のデータソースで、グラフは選択した Dataset の列とデータの内容に基づいて生成されます。

Dataset の一覧では、データセットの名前、種類、データベース、Schema、所有者、最終更新日時を確認できます。

## 注意事項

レポートで確認できる Dashboard、Chart、Dataset は、ユーザーの権限によって異なります。特定のレポートやデータセットが表示されない場合は、対応する閲覧権限または管理権限を持っているかを確認してください。

このページは主にデータの閲覧と分析に使います。Dashboard、Chart、Dataset を調整する必要がある場合は、レポートの管理権限を持っているかを確認したうえで、必要に応じて設定してください。
